# Class 5 - Intro to n8n #2: Automation Fundamentals



## Lesson Overview

This lesson focused on building the first real automation workflow in n8n — covering the core building blocks: how data flows between nodes, how to use logic to make decisions, and how to route information to different places based on conditions.

By the end of this lesson, the goal is to understand how to connect nodes together and build workflows that actually work.

## What This Lesson Covers

- How to set up a first n8n workflow
- How to connect nodes and pass data between them
- How to use logic to make decisions in a workflow
- How to route data to different paths based on conditions
