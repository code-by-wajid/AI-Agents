# Class 1 - Intro to AI & Agentic Thinking

## What is AI?

Artificial Intelligence (AI) is the ability of a machine or system to perform tasks that normally require human intelligence — such as reasoning, learning, problem-solving, and decision-making.

## Types of AI

### By Capability

1. **Narrow AI (Weak AI)**
   - AI designed to perform a specific task only.
   - Example: Siri, Google Translate, spam filters, recommendation systems (Netflix, YouTube).

2. **Artificial General Intelligence (AGI)**
   - Hypothetical AI with human-level intelligence across all domains.
   - Can learn, understand, and apply knowledge like a human — not built yet.

3. **Artificial Superintelligence (ASI)**
   - Hypothetical AI that surpasses human intelligence in every field.
   - A future concept, widely discussed in AI safety and research circles.

### By Functionality

4. **Reactive Machine AI**
   - No memory, responds only to current input.
   - Example: IBM's Deep Blue (chess-playing AI).

5. **Limited Memory AI**
   - Can use past data/experiences to make current decisions.
   - Example: Self-driving cars, chatbots like ChatGPT/Claude.

6. **Theory of Mind AI**
   - Hypothetical AI that could understand emotions, beliefs, and intentions of others.
   - Still in research/theoretical stage.

7. **Self-Aware AI**
   - Hypothetical AI with consciousness and self-awareness.
   - Purely theoretical — does not exist yet.

## How an AI Agent Works

An AI agent is built on three core components:

1. **Memory**
   - Stores past interactions/context so the agent can maintain continuity in conversations or tasks.

2. **Tools**
   - External functions or APIs the agent can call to take actions (e.g., search the web, send an email, query a database).

3. **LLMs / Models**
   - The "brain" of the agent — processes input, reasons, and generates responses or decisions.

## APIs and Webhooks

- **API (Application Programming Interface)**
  - A way for two applications/systems to communicate with each other.
  - Example: Requesting data from a weather service to display in an app.

- **Webhook**
  - A way for one application to send real-time data to another application automatically when a specific event happens.
  - Example: Getting notified instantly when a new order is placed on an e-commerce site.
