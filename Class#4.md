# Class 4 - Intro to N8N #1: Agent Fundamentals


## Lesson Overview

This lesson covers the core building blocks of AI agents in **n8n** — the essential components that power every intelligent automation system, from how agents receive input to how they generate responses and take actions.

By the end of this lesson, the goal is to understand how to build basic AI agents that can interact with users, remember context, and execute tasks automatically.

## What This Lesson Covers

- What AI agents are and how they work
- The 5 core components of every n8n agent
- How to configure **trigger nodes** to start conversations
- How to use **action nodes** to execute tasks
- How to write effective **prompts (system prompts)**
- How to choose and configure **LLMs (Large Language Models)**
- How **memory** works in AI agents
